# MonitorGenshin

**A lightweight Windows utility that automatically closes lingering Genshin Impact processes.**

**Uma ferramenta leve para Windows que encerra automaticamente processos do Genshin Impact que continuam abertos em segundo plano.**

---

## 🇺🇸 English

### The problem

Sometimes, after closing Genshin Impact, its process remains running in the background, preventing the game from being launched again.

### The solution

MonitorGenshin runs in the Windows system tray and monitors Genshin Impact processes.

### Features

- Automatically attempts to close the game process after its window closes.
- Attempts to clean up processes that remain running during startup.
- Displays a Windows notification after attempting to close a process.
- Runs quietly in the system tray.
- Can be stopped from the system tray menu.

### Requirements

- Windows.
- No separate Python installation is required when using the packaged executable.

### How to use

1. Download `MonitorGenshin.exe` from the project's **Releases** page.
2. Run the executable.
3. Launch Genshin Impact normally.
4. MonitorGenshin will run in the background.
5. To stop the monitor, right-click its system tray icon and select **Sair**.

### Disclaimer

MonitorGenshin is an unofficial community project. It is not affiliated with or endorsed by HoYoverse.

Use at your own discretion. The application may terminate the Genshin Impact process when it detects that the game window has closed.

## 🇧🇷 Português

### O problema

Às vezes, depois de fechar o Genshin Impact, o processo do jogo continua aberto em segundo plano, impedindo que o jogo seja iniciado novamente.

### A solução

O MonitorGenshin fica na bandeja do sistema do Windows e monitora os processos do Genshin Impact.

### Funcionalidades

- Tenta encerrar o processo do jogo depois que a janela é fechada.
- Tenta encerrar processos que permanecem abertos durante a inicialização.
- Exibe uma notificação do Windows após tentar encerrar um processo.
- Funciona silenciosamente em segundo plano, na bandeja do sistema.
- Pode ser encerrado pelo menu do ícone na bandeja.

### Requisitos

- Windows.
- Não é necessário instalar o Python separadamente ao utilizar o executável compilado.

### Como usar

1. Baixe o `MonitorGenshin.exe` na página **Releases** do projeto.
2. Execute o arquivo.
3. Abra o Genshin Impact normalmente.
4. O MonitorGenshin funcionará em segundo plano.
5. Para encerrar o monitor, clique com o botão direito no ícone da bandeja e selecione **Sair**.

### Aviso

O MonitorGenshin é um projeto comunitário não oficial, sem afiliação ou aprovação da HoYoverse.

Use por sua conta e risco. O aplicativo pode encerrar o processo do Genshin Impact quando detecta que a janela do jogo foi fechada.
